# 🤖 BotForge

BotForge is an advanced, production-ready AI Chatbot Infrastructure that allows users to transform any website URL into a smart, context-aware AI chatbot. By crawling website content, building a robust knowledge base, and generating an easily embeddable widget, BotForge empowers any business to offer instant automated support in seconds.

---

## 🚀 Features

*   **Real-time Website Crawler**: Seamlessly crawls target websites, extracting pages and breaking content into optimized chunks for LLM ingestion.
*   **Knowledge Base Generation**: Automatically structures crawled content into a searchable knowledge base for the AI model.
*   **Embeddable Widget**: Provides a simple HTML `<script>` tag that users can copy and paste into their websites to deploy their customized chatbot instantly.
*   **Comprehensive Admin Dashboard**:
    *   Monitor total users, websites crawled, ongoing conversations, and subscription statuses (Free vs. Paid/Agency).
    *   Manage and search users, adjust subscription plans, assign admin privileges, or delete accounts.
*   **Modern SaaS Landing Page**: Designed with interactive UI components highlighting features, dark/light mode toggle, pricing plans, and quick onboard options.
*   **Enterprise-Grade Standards**: Built to be secure, scalable, and reliable.

---

## 🛠️ Tech Stack

This project is built using a modern full-stack architecture:

*   **Frontend**: React (Vite), Tailwind CSS
*   **Backend/API**: Node.js / Laravel (as per your architecture configuration)
*   **Database & Vector Search**: Database storage coupled with vector search capabilities for content chunk retrieval.
*   **AI Integration**: Large Language Models (LLMs) for understanding website context and generating accurate responses.
